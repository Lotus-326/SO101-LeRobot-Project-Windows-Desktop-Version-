# 10 · 数据集工具（lerobot-edit-dataset）

> 对应官方 Wiki：[SO-Arm 数据集工具](https://wiki.seeedstudio.com/cn/lerobot_dataset_tool/)

全部操作都由脚本 `scripts\11-edit-dataset.ps1` 包装好了。

## 1. 删除剧集

**直接改原数据集**（危险，会原地重建）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action delete-episodes -Episodes "0,2,5"
```

**另存为新数据集，保留原件**（推荐）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action delete-episodes -Episodes "0,2,5" `
  -NewRepoId seeedstudio123/m1_pick_cube_clean
```

> 适用场景：某几个 episode 录废了（掉件、撞台面、遮挡），删掉再训练。

---

## 2. 拆分数据集

按比例（80% / 10% / 10%）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action split -Splits '{"train":0.8,"test":0.1,"val":0.1}'
```

按 episode 编号：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action split -Splits '{"task1":[0,1,2,3],"task2":[4,5]}'
```

拆出来的数据集以后缀形式命名：`<原 repo_id>_train` / `_test` / `_val`。

> ⚠️ 实测提醒：episode 很少时（例如只有 3 个），按比例拆可能算出
> `val` 拿到 0 个 episode，官方会打 `Split 'val' has no episodes, skipping...`。
> 属于正常现象，数据量上来（≥20 个）就不会了。

## 3. 合并数据集

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action merge -RepoId seeedstudio123/m1_merged `
  -RepoIds "seeedstudio123/m1_pick_cube_train,seeedstudio123/m1_pick_cube_val"
```

合并后 episode 数和帧数是各源之和。

## 4. 移除特征

典型场景：**录的时候挂了两个相机，训练只想用一个。**

```powershell
# 先看一眼有哪些特征
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 -Action info
#   observation.images.front  <-  video
#   observation.images.side   <-  video

# 去掉 side 相机，另存新数据集
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action remove-feature -Features "observation.images.side" `
  -NewRepoId seeedstudio123/m1_pick_cube_frontonly
```

> ⚠️ 去掉特征后要**用它重新训练**；评估时 `--robot.cameras` 的键名也必须跟着少掉 side，
> 否则报 `mean is infinity`。

## 5. 图片数据集转视频

如果你采集时用了 `06-record.ps1 -NoVideo`（存 PNG，很占空间），可以事后转成视频：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action convert-video -NewRepoId seeedstudio123/m1_pick_cube_video
```

自定义编码器 / 质量 / 并行度：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action convert-video -NewRepoId seeedstudio123/m1_pick_cube_video `
  -VCodec h264 -Crf 30 -NumWorkers 8
```

| 参数 | 含义 | 可选值 |
| --- | --- | --- |
| `-VCodec` | 编码器 | `libsvtav1`（默认，体积最小）/ `h264`（编码快）/ `hevc` |
| `-Crf` | 质量，越小越好越大 | 0（无损）~ 51，默认 30 |
| `-NumWorkers` | 并行进程数 | 默认 4 |

## 9. ⚠️ 三个必须知道的坑（本项目已实测并规避）

### 9.1 `--root` 语义在本版本里是矛盾的

| 代码位置 | 对 `root` 的理解 |
| --- | --- |
| `LeRobotDatasetMetadata.__init__` | `root` = **数据集完整目录** |
| `lerobot_edit_dataset.get_output_path` | `root` = **父目录**（再拼 `repo_id`） |

两边不一致，所以**传 `--root` 一定有一边错**：读不到数据集（转去 Hub → 401），
或者输出被多套一层目录。

**本脚本的做法：完全不传 `root`**，让它走默认的
`%USERPROFILE%\.cache\huggingface\lerobot\<repo_id>`。
想换存放位置就设 `HF_LEROBOT_HOME`（读写两端会同步改变）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\11-edit-dataset.ps1 `
  -Action list -LerobotHome D:\lerobot-data
```

### 9.2 数据集不在本地时它会去挤 HuggingFace Hub

`LeRobotDataset` 找不到本地 `meta/info.json` 时，会 `pull_from_repo()` 去 Hub 拉。
没网/没代理就是 `ConnectTimeout`，或者 `401 RepositoryNotFoundError`。

**所以：先确认 `-Action list` 里能看到你的数据集，再做编辑操作。**

### 9.3 本脚本用 JSON 配置文件而不是命令行参数

PowerShell 传 JSON 给 exe 时，里面的双引号会被转义规则搞坏
（`--operation.splits '{"train":0.8}'` 这类）。本脚本改成：

```
把参数写成 JSON 文件 → lerobot-edit-dataset --config_path=<文件>
```

命令行里一个引号都不用，稳定可靠。生成的配置文件在
`outputs\edit-configs\<动作>-<时间戳>.json`，加 `-DryRun` 可以只生成不执行，
`-ShowCommand` 会打印等价的原生命令。

## 10. 自测用假数据集

没有机械臂也想验证这套工具链？仓库里带了生成器：

```powershell
# 生成 3 episodes × 20 帧 × 2 相机的假数据集（视频格式）
powershell -ExecutionPolicy Bypass -File scripts\shell.ps1
python ..\_tools\make_dummy_dataset.py

# 再生成一个图片格式的（用来测 convert_image_to_video）
python ..\_tools\make_dummy_dataset.py --no-videos

# 用完删掉
python ..\_tools\make_dummy_dataset.py --cleanup
```

本项目已经用它们把 **list / info / delete-episodes / split / merge /
remove-feature / convert-image-to-video / dataset-viz** 全部跑通了一遍。
