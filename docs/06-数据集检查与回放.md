# 06 · 数据集检查与回放

录完数据**先检查再训练**。这一步能省掉几小时的无效训练。

---

## 1. 目录结构

```
%USERPROFILE%\.cache\huggingface\lerobot\seeedstudio123\m1_pick_cube\
├─ data\        episode 的 parquet（关节状态、动作、时间戳）
├─ videos\      每个相机、每个 episode 一段 mp4
├─ meta\        info.json / stats.json / tasks.jsonl / episodes\
└─ ...
```

快速看一眼：

```powershell
$ds = "$env:USERPROFILE\.cache\huggingface\lerobot\seeedstudio123\m1_pick_cube"
Get-ChildItem $ds, "$ds\meta" | Select-Object Name
Get-Content "$ds\meta\info.json" | Select-Object -First 40
```

`info.json` 里重点确认：

- `total_episodes` —— 录了几个
- `fps` —— 是不是 30
- `features` —— 相机键名（`observation.images.front` 等）和 `action` 维度
- `codebase_version` —— 数据集格式版本（训练/评估必须同版本）

---

## 2. 可视化（rerun）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\08-dataset-viz.ps1 -EpisodeIndex 0
```

会弹出 **rerun** 本地查看器，逐帧看图像 + 关节曲线。

导出成文件（不弹窗，便于留档 / 发给别人）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\08-dataset-viz.ps1 -EpisodeIndex 0 -Save
# 生成到 lerobot\outputs\rrd\
```

> 注：`--display-compressed-images` 默认 false（看未压缩帧）。
> 想确认「训练时实际看到的压缩画质」，加 `-DisplayCompressedImages`。

---

## 3. 回放到真机

把某个 episode 的动作**原样重放**到 Follower 上，验证「录下来的动作」和
「当时真实发生的动作」一致：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\07-replay.ps1 -Episode 0
```

⚠️ 回放会直接驱动机械臂，务必先清空工作空间。

如果回放的动作和当时遥操作的动作差别很大 → 数据有问题，别急着训练。

---

## 4. 检查清单

- [ ] `total_episodes` 与预期一致
- [ ] 每个 episode 的视频都能正常播放、全程有画面
- [ ] 目标物体全程在画面内，没有被遮挡
- [ ] 光照、相机角度没有中途变化
- [ ] 没有明显失败的 episode（掉件、撞台面）—— 有就用 `lerobot-edit-dataset` 删掉重录
- [ ] `meta\stats.json` 存在且不是空/全零（`mean is infinity` 的根源）

---

## 5. 数据集编辑

LeRobot 自带编辑脚本，可以删除/拆分/合并 episode：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\shell.ps1
lerobot-edit-dataset --help
```

更多见离线文档 `_wiki\lerobot_dataset_tool.md`。
